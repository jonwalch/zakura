## Fixed

- Fixed contextual difficulty validation accepting an incomplete predecessor
  context. A context shorter than the height-dependent span silently produced
  the easiest possible expected difficulty; it is now rejected as not ready to
  be committed. This is reachable through header sync and non-checkpointed test
  networks, which are the only paths that run contextual validation on the early
  chain ([#675](https://github.com/zakura-core/zakura/pull/675)).
- Fixed two overflow paths in the difficulty adjustment. The threshold
  calculation no longer multiplies before clamping to the network's target
  difficulty limit, and the mean target is now computed exactly instead of
  summing seventeen expanded targets before dividing, which a custom network
  with a large proof-of-work limit could overflow
  ([#675](https://github.com/zakura-core/zakura/pull/675)).
