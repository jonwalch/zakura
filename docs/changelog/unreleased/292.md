## Changed

- Isolated block template and shielded coinbase construction from asynchronous
  RPC worker threads, preventing expensive proving work from delaying unrelated
  RPC requests ([#292](https://github.com/zakura-core/zakura/pull/292)).
- Bounded concurrent `getblocktemplate` construction: external RPC calls fail
  fast with a "server is busy" error when construction capacity is exhausted,
  while the internal miner and `generate` are exempt from the limit and keep
  working under external load
  ([#292](https://github.com/zakura-core/zakura/pull/292)).
